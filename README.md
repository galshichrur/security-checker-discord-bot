# Security Checker Discord Bot

<p align="left">
  <img src="./logo.png" alt="Security Checker Bot Logo" width="90" style="vertical-align: middle;"/>
</p>

A simple Discord bot that adds a security verification check before users can access a server.

When a user requests access, it opens a private channel, asks them a few questions (like name, age, gender), and sends their answers to staff. Staff can then either approve or reject them. If approved, the bot automatically gives the user a verified role, moves the channel to an archive, and locks it.

⚠️ Don’t even try using the hardcoded bot token :)
